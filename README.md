# Block Blast Auto-Solver 

Привет! Это мой пет-проект - скрипт-помощник (чит) для мобильной игры Block Blast. 
Пишу чисто для фана и практики. Проект пока в процессе разработки (WIP), но уже умеет кое-что интересное.

## Как это работает
Скрипт подключается к телефону через ADB, захватывает экран (через scrcpy) и анализирует поле. 
В файле `brain.py` крутится логика: он смотрит на скриншот, находит свободные слоты, распознает фигуры через маски и пытается понять, куда их лучше воткнуть.

Зацени скрины того, как скрипт «видит» игру (в папке с дебагом можно найти маски и выделенные ROI).

## Стек
* **Python** (`main.py` + `brain.py`)
* **ADB / Scrcpy** — для коннекта к телефону и симуляции тапов
* **OpenCV** — для работы с изображениями и масками фигур

## Запуск (для себя на будущее)
1. Подрубить телефон по USB (с включенной отладкой).
2. Закинуть бинарники Scrcpy и ADB в папку проекта (в гите их нет, чтобы не мусорить).
3. Запустить `python main.py`.
